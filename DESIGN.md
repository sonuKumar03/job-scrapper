# Local job dashboard

Approved direction: a restrained operations interface for reading jobs and managing scrapes.

## Visual rules

Use a warm off-white page, white content surfaces, dark neutral text, and a forest-green action accent. System sans-serif for interface text, monospace only for raw identifiers. Dense but readable job rows; long descriptions retain comfortable line length and whitespace. Use thin rules and spacing rather than decorative cards, gradients, charts, or imagery.

## Layout and interaction

Persistent compact header with Jobs and Scrape runs navigation. Jobs uses a toolbar, a real table on desktop, and rows as cards on mobile. Job detail uses an addressable page with a back link; fetched attributes and sightings follow the full description. Runs uses a selection form followed by durable history and account results. Buttons are explicit; statuses are text with color as a secondary cue. Labels, keyboard focus, live announcements, and safe text rendering are required.
